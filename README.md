# 座布団マン（ZABUTON MAN）

旅館の大広間で、左右に揺れる座布団の山のど真ん中に飛び乗るゲーム。
HTML1枚だけで動く（ビルド・サーバー不要）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホでもPCでも動く。

- 下の **ジャンプ** ボタン（またはスペースキー／画面タップ）で、右に立つ男がジャンプする
- 座布団は左右に揺れている。**着地する瞬間に座布団が真ん中に来るタイミング**で押す
- 成功 → 男は座布団の上で**膝を90度に折った膝立ちで静止**、座布団が1枚増えて次のチャレンジ
- 失敗 → 座布団が飛び散り、**記録（枚数）**が出て1枚から再スタート
- 自己ベストはブラウザに保存される（localStorage）

## 登場キャラ（毎ターン抽選）

| 確率 | キャラ |
|---|---|
| 60% | 爽やかな大学生（基本） |
| 30% | メガネのオタク |
| 10% | 白いブリーフ一丁の男 |

## 30%で出るメガネのオタク

- オタクは後ろから仲間にずっと座布団で殴られている
- オタクは**異常に高く跳ぶ**（滞空時間が長い＝着地位置の予測が難しい）
- オタクが成功したときは通常どおり座布団が増える
- オタクが失敗したときは**座布団は飛び散らない**。激昂して座布団を持ち仲間を追いかけ回す
  - 追跡パートは「こうげき！」ボタンの当てゲーム（制限7秒）
  - 仲間は壁際に追い詰められると横をすり抜けて逃げる。**すれ違う瞬間**が狙い目
  - 撃破できれば **「再チャレンジ権獲得」**。同じ枚数からやり直せる（失敗にならない）
  - 逃げ切られたら通常の失敗（座布団が飛び散って1枚から）

## 10%で出るブリーフ男

**どのタイミングで押しても必ず成功する**ボーナスキャラ。

- ジャンプした瞬間に座布団の揺れが止まり、**座布団のほうがぷるぷる寄ってきて**真下に収まる
- 本人は空中で2回転しながら星をまき散らす
- 着地すると **「座布団マン」** が金文字で大きく出て（`msg()` の第4引数 `big`）、通常どおり座布団が1枚増える
- 実装は `judge()` の最初で `chara==='brief'` を成功として扱い、飛行中に `zxFrozen` を
  `CENTER` へイージングで寄せているだけ（判定に例外を作らず、位置のほうを動かしている）

## 難易度の作り

| 要素 | 変化 |
|---|---|
| 揺れ幅 | `52 + 枚数×5`（最大132px） |
| 揺れ速度 | `1.5 + 枚数×0.13` rad/s（最大4.2） |
| 成功判定 | 座布団の中心から **±30px** 以内に着地 |
| 滞空時間 | 大学生 0.88秒 / オタク 1.55秒 / ブリーフ 1.25秒 |

成功後は揺れの位相をランダムにずらしているので、「ボタンを即押しし続ける」では安定して勝てない。

## 画面サイズへの追従（スマホ対策）

論理解像度を固定にすると、縦長のスマホでは横に合わせて縮むせいでゲーム画面が
極端に小さくなる。そこで `resize()` で**世界の寸法そのものを画面の形に合わせて決めている**。

| 値 | 決め方 |
|---|---|
| `W`（横） | `520 × 画面幅/画面高` を **480〜800** に丸める。縦長なほど狭く＝拡大表示になる |
| `H`（縦） | 余った縦を **520〜600** の範囲で畳の手前に足す |
| `STARTX` | `W - max(100, 132×W/800)`。狭いほど男を右端に寄せる |
| `CENTER` | 振れ幅132が取れるなら `W/2`。取れないなら左に寄せて振れ幅を稼ぐ |
| `AMPMAX` | 左端55と男の手前までに収まる最大値（上限132） |

背景・HUD・追跡パートの座標も全部 `W`/`H` 基準にしてある。**座標をベタ書きしないこと**。
追跡の命中範囲とキャラの移動速度も `W/800` を掛けて、狭い画面でも難易度が変わらないようにしている。

iPhone想定（375×812）で 横480×縦600 の世界になり、キャンバスは 355×444px。
固定800×520だったときの 349×227px から**約2倍**の大きさになる。

## 中身

すべて `index.html` に入っている（Canvas 2Dに直接描画。画像・音声ファイルなし）。

- `POSE` … 関節座標で定義したポーズ。`poseLerp()` で補間してアニメーションする
  - `kneel` が成功時のポーズ（膝を90度に後ろへ折り、すねを座布団につけた膝立ち。上体は垂直）
- `drawPerson()` … 4種類のキャラ（`student` / `otaku` / `brief` / `friend`）を描き分ける
- `drawRoom()` … 旅館の大広間（天井の梁・提灯・障子・床の間の掛け軸・畳）
- `drawZabuton()` … 座布団1枚。山・手持ち・飛び散りで使い回す
- 状態遷移 … `title → ready → jump → success → grow → ready` / 失敗で `fail` / オタク失敗で `rage → chase → chaseHit`
- 効果音はWebAudioで合成（右上のボタンでON/OFF）
