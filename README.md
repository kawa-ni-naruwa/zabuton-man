# 座布団マン（ZABUTON MAN）

旅館の大広間で、左右に揺れる座布団の山のど真ん中に飛び乗るゲーム。
HTML1枚だけで動く（ビルド・サーバー不要）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホでもPCでも動く。

- 下の **ジャンプ** ボタン（またはスペースキー／画面タップ）で、右に立つ男がジャンプする
- 座布団は左右に揺れている。**着地する瞬間に座布団が真ん中に来るタイミング**で押す
- 成功 → 男は座布団の上で**膝を90度に曲げて静止**、座布団が1枚増えて次のチャレンジ
- 失敗 → 座布団が飛び散り、**記録（枚数）**が出て1枚から再スタート
- 自己ベストはブラウザに保存される（localStorage）

## 3回に1回はメガネのオタク

- ターンが3の倍数のとき、キャラが**メガネのオタク**に変わる
- オタクは後ろから仲間にずっと座布団で殴られている
- オタクは**異常に高く跳ぶ**（滞空時間が長い＝着地位置の予測が難しい）
- オタクが成功したときは通常どおり座布団が増える
- オタクが失敗したときは**座布団は飛び散らない**。激昂して座布団を持ち仲間を追いかけ回す
  - 追跡パートは「こうげき！」ボタンの当てゲーム（制限7秒）
  - 仲間は壁際に追い詰められると横をすり抜けて逃げる。**すれ違う瞬間**が狙い目
  - 撃破できれば **「再チャレンジ権獲得」**。同じ枚数からやり直せる（失敗にならない）
  - 逃げ切られたら通常の失敗（座布団が飛び散って1枚から）

## 難易度の作り

| 要素 | 変化 |
|---|---|
| 揺れ幅 | `52 + 枚数×5`（最大132px） |
| 揺れ速度 | `1.5 + 枚数×0.13` rad/s（最大4.2） |
| 成功判定 | 座布団の中心から **±30px** 以内に着地 |
| 滞空時間 | 大学生 0.88秒 / オタク 1.55秒 |

成功後は揺れの位相をランダムにずらしているので、「ボタンを即押しし続ける」では安定して勝てない。

## 中身

すべて `index.html` に入っている（Canvas 2Dに直接描画。画像・音声ファイルなし）。

- `POSE` … 関節座標で定義したポーズ。`poseLerp()` で補間してアニメーションする
  - `land90` が成功時の「膝90度」ポーズ（すね垂直・ももが水平）
- `drawPerson()` … 3種類のキャラ（`student` / `otaku` / `friend`）を描き分ける
- `drawRoom()` … 旅館の大広間（天井の梁・提灯・障子・床の間の掛け軸・畳）
- `drawZabuton()` … 座布団1枚。山・手持ち・飛び散りで使い回す
- 状態遷移 … `title → ready → jump → success → grow → ready` / 失敗で `fail` / オタク失敗で `rage → chase → chaseHit`
- 効果音はWebAudioで合成（右上のボタンでON/OFF）
